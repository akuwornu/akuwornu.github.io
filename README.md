# akuwornu.github.io

Personal academic website of **Anani Yao Kuwornu**, Ph.D. candidate in Communication at the University of Maryland, College Park.

Live at https://akuwornu.github.io

## Structure

- `index.html` – home: bio, research summary, selected publications, teaching, experience, contact
- `research/` – dissertation, publications, presentations, grants
- `teaching/` – courses, evaluations, mentoring
- `cv/Kuwornu_CV.pdf` – current CV
- `assets/css/style.css` – shared styles
- `images/` – portrait and social preview image

Plain HTML and CSS, no build step. Edit a page and push; GitHub Pages republishes automatically.
